# Non-technical shared sync setup and guidance
#story/backlog Guide non-technical users through configuring shared collaboration for their planning data from the Tauri desktop app so Publish and Refresh work without terminal knowledge.

## Description

Guide non-technical users through configuring shared collaboration for their planning data from the Tauri desktop app so Publish and Refresh work without terminal knowledge.

## Acceptance Criteria
- The app provides a guided way to connect the active data folder to a shared collaboration target.
- The GUI explains Publish and Refresh in non-technical language while surfacing actionable remediation when setup is incomplete.
- The app prevents unsafe collaboration actions when required sync prerequisites are missing.
- Automated tests cover representative success and failure paths for shared-sync setup.
