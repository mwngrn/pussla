# Implement REQ_PUSSLA_012: hide/show past weeks and months in dashboard
#story/backlog Add dashboard controls to hide or show past periods so planners can focus on the current week and future periods while still being able to re-enable historical context.

## Description

Add dashboard controls to hide or show past periods so planners can focus on the current week and future periods while still being able to re-enable historical context.

## Acceptance Criteria
- Dashboard provides controls to hide/show past weeks and past months.
- When past periods are hidden, the current week and future periods remain visible.
- Users can re-enable visibility of past weeks and past months without reloading data.
- Automated tests cover period filtering behavior for both hidden and shown states.
