# Installer and release packaging for non-technical users
#story/backlog Produce installable Tauri desktop distributions and a repeatable release workflow so non-technical users can install and update Pussla without manual environment setup.

## Description

Produce installable Tauri desktop distributions and a repeatable release workflow so non-technical users can install and update Pussla without manual environment setup.

## Acceptance Criteria
- Build outputs exist for the target desktop platform(s) in an installable Tauri form.
- The release workflow bundles the required runtime and assets for the Tauri desktop app.
- Installation and update instructions are documented for non-technical users.
- Release verification covers clean install and first launch behavior.
