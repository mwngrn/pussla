# Implement staffing lookup by required role and skill (REQ_PUSSLA_011)
#story/backlog Provide a way to identify available people for a project by filtering on required role and skill using existing planning availability data.

## Description

Provide a way to identify available people for a project by filtering on required role and skill using existing planning availability data.

## Acceptance Criteria
- A user can request candidates by required role and skill.
- Results include only people with matching role and skill.
- Results account for planning availability for the requested period.
- Automated tests verify positive and negative matching scenarios.
